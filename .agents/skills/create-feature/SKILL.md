# Create Feature

Apply [Create Issue](../create-issue/SKILL.md) with category **Feature**. Resolve open behavior, scope, and acceptance decisions with the user before creation. Use [Technical Writing](../technical-writing/SKILL.md) to write the final agreed outcome concisely, with relevant Wiki links. Create or reuse the issue and verify Compallm board membership.
