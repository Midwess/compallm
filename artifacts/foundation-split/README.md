Design foundations contains ten families: visual constants, text fields, buttons and links, dropdown controls, selection controls, feedback and overlays, content/code primitives, form primitives, navigation controls, and data primitives.

Complete sidebars, screens, forms, and complex feature assemblies live on dedicated pages: Sidebar, Forms, Preferences, Projects, Billing, AI & integrations, Documents, Reviews, and Add provider. Main was renamed Add provider. Login, Signup, and icon pages remain in place.

The Page patterns gallery is removed. Existing live screen edits were preserved. The retired featured-card master had no instances and was removed.

[verification.json](verification.json) records transfers, page contents, component links, the restored field-propagation probe, gallery spacing bindings/bounds, and full-file validation. No missing component links were found across the twelve audited design pages. The live custom-configuration prototype link recorded before the provider-page cleanup remains present.

Fresh exports: [Form primitives](form-primitives.png), [Buttons](buttons.png), and [Provider screen](provider-selected.svg). The matching SVG files embed fonts. The final saved version is **Design foundations · bases only · dedicated pages complete**.
