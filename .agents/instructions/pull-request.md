# Pull requests

Work can start without an issue. Before creating a PR, use [Related Issues](../skills/related-issues/SKILL.md) to inspect the current Compallm PR, branch context, and existing issue links. Reuse relevant linked issues without asking again. If no related issue is established, ask the user to identify an existing issue or have the agent create one using [Create Issue](../skills/create-issue/SKILL.md), [Create Feature](../skills/create-feature/SKILL.md), [Create Bug](../skills/create-bug/SKILL.md), or [Create Task](../skills/create-task/SKILL.md). New issues belong in `Midwess/compallm` and the [Compallm Project](https://github.com/orgs/Midwess/projects/7). Then create the PR and link its issues using [Link Issue](../skills/link-issue/SKILL.md). Only PR creation waits for missing issue selection; continue authorized preparation and verification. Documentation-first requirements below still apply.
