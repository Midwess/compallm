# Linear control surfaces

Shared button and dropdown masters use the supplied Linear H2D capture treatments. These previews preserve the user's revised first provider page and apply the compact progress layout to its selected and configuration states.

Matching SVGs embed the captured Inter fonts. PNGs are local renders of fresh Penpot SVG exports. [verification.json](verification.json) records 20 shared button states, 25 dropdown/menu surface parts, the restored master-to-instance propagation probe, 13 valid navigation links, page audits, and the named saved version. The library has 231 masters in 40 variant groups across fourteen frames.

Neutral filled controls use a 0.5 px white shadow edge at 14% opacity and a black 30% shadow with y = 0.5, blur = 1, spread = 1. Primary actions use the black shadow with a transparent half-pixel border. Ghost/link treatments stay transparent; focus rings and disabled opacity retain their roles. Dropdown triggers use a 14.3% white shadow edge with the same small black shadow; menus use a real 0.5 px `#3C3D40` border and three 12.5% black shadow layers. Surface geometry is independent of spacing density.

Source measurements come from the supplied preferences, application, billing, and connector H2D captures. See [Portal control rules](../../docs/content/portal/controls.md#button-surfaces). No React/application integration is included.
