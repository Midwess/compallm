# Create Bug

Apply [Create Issue](../create-issue/SKILL.md) with category **Bug**. Resolve open expected-behavior and scope decisions with the user before creation. Use [Writing](../writing/SKILL.md) to describe observed versus expected behavior, available reproduction evidence, impact, and agreed completion criteria concisely. An unknown cause is not an unanswered product requirement; do not invent a diagnosis. Create or reuse the issue and verify Compallm board membership.
